# RenfortPro — prototype de site

Prototype front-end responsive (HTML/CSS/JS sans framework ni backend).

## Ouvrir
Ouvrir `index.html` dans un navigateur. Aucun outil ni installation n'est nécessaire.

## Contenu actuel
- Page d'accueil et identité RenfortPro provisoire
- Entrées Entreprises / Indépendants
- Recherche de démonstration de profils et de missions (filtres métier/localisation)
- Tarifs illustratifs : 10 €/mois entreprise, gratuit indépendant
- Espace partenaires
- Navigation mobile

Les profils, missions, comptes, formulaires et tarifs affichés sont des exemples. Aucun compte, paiement, publication ou contact réel n'est connecté.
